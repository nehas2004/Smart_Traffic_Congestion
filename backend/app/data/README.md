# Canonical traffic data foundation

`corridors.csv` is the authoritative synthetic corridor registry for the
traffic module.  Its six stable IDs are the only IDs future traffic readings,
predictions, bottlenecks, and API responses should use.

`synthetic_traffic_history.csv` is generated by
`generate_synthetic_traffic.py`.  It contains 21 days of 15-minute readings
(12,096 rows) and is deterministic with seed `20260819`.

The target is the dimensionless Travel Time Index (TTI):

```text
congestion_index = actual_travel_time_sec / free_flow_travel_time_sec
                 = free_flow_speed_kmph / actual_speed_kmph
```

The dataset is explicitly synthetic.  `rainfall_mm` and `temperature_c` use a
deterministic weather-like context compatible with the approved Open-Meteo
field names; it does not claim that this generated file is an Open-Meteo
historical export.  Replacing it with cached Open-Meteo history is a later ETL
step and must preserve the same field names and 15-minute corridor cadence.

`lag_15`, `lag_30`, `lag_60`, and `rolling_1h_avg` are prior TTI values from
the same corridor.  They are never copied from the current observation.
